# Лабораторна робота №1. Візуальне моделювання фігур Ліссажу

## Мета роботи
Розробити WPF-застосунок для побудови та дослідження параметричних кривих Ліссажу за принципом розділення відповідальності (Model — ViewModel — View), перевірити вплив частот, амплітуд, початкових фаз та кроку дискретизації на форму графіка.

## Математична модель
Траєкторія точки задається системою рівнянь гармонічних коливань по двох перпендикулярних осях:

$$x(t) = A_x \sin(2\pi f_x t + \varphi_x)$$
$$y(t) = A_y \sin(2\pi f_y t + \varphi_y)$$

де:
- $A_x, A_y$ — амплітуди коливань (од., `0.1–10`);
- $f_x, f_y$ — частоти коливань (Гц, `0.1–20`);
- $\varphi_x, \varphi_y$ — початкові фази (вводяться у градусах `0–360°`, перед обчисленням переводяться в радіани);
- $\Delta t$ — крок часу дискретизації (с), що забезпечує щонайменше 20 точок на найменший період $T_{\min} = 1 / \max(f_x, f_y)$.

## Висновки щодо властивостей фігур Ліссажу
1. **Співвідношення частот $f_x : f_y$** визначає загальну складність і замкненість фігури: для простих раціональних співвідношень (`1:1`, `1:2`, `2:3`, `3:4`) крива швидко замикається та утворює сталу кількість петель по горизонталі й вертикалі.
2. **Різниця фаз $\Delta\varphi = |\varphi_y - \varphi_x|$** змінює орієнтацію та форму кривої: при $f_x = f_y$ та $\Delta\varphi = 0^\circ$ фігура вироджується у пряму діагональну лінію, а при $\Delta\varphi = 90^\circ$ та $A_x = A_y$ перетворюється на коло (за однакового масштабу по осях).
3. **Амплітуди $A_x, A_y$** задають габарити прямокутника, в який вписана фігура.
4. **Крок часу $\Delta t$** впливає лише на гладкість ламаної (кількість точок апроксимації): зменшення $\Delta t$ робить криву плавнішою, не змінюючи її геометричної форми. Занадто великий крок призводить до викривлення кривої або «зрізаних» кутів.

## Архітектура проєкту
- `LissajousApp/Models/` — чиста предметна модель (`PointD`, `LissajousParameters`, `LissajousModel`) без залежності від WPF (`System.Windows`). Містить обчислення точок, валідацію параметрів та рівномірне масштабування в екранні координати з інверсією осі $Y$.
- `LissajousApp/Commands/` — `RelayCommand` (`ICommand`).
- `LissajousApp/ViewModels/` — `MainViewModel` (`INotifyPropertyChanged`), який зберігає стан полів, синхронізує текстові поля та слайдери, виконує покрокову валідацію з повідомленнями біля відповідних полів та формує `PointCollection` для графіка.
- `LissajousApp/MainWindow.xaml` — інтерфейс користувача на базі розмітки `Grid`, `StackPanel`, `DockPanel`, `WrapPanel` і `Canvas` + `Polyline`.
- `LissajousApp.Tests/` — модульні тести (`xUnit`) для перевірки математичної моделі.

## Контрольні приклади
| Тип | Вхідні дані | Очікуваний результат |
|---|---|---|
| Нормальний (1:1 коло) | $A_x=3, A_y=3, f_x=2, f_y=2, \varphi_x=0^\circ, \varphi_y=90^\circ, \Delta t=0.005$ | Замкнене коло радіусом 3 без спотворення пропорцій |
| Нормальний (2:3) | $A_x=3, A_y=3, f_x=2, f_y=3, \varphi_x=0^\circ, \varphi_y=90^\circ, \Delta t=0.003$ | Симетрична замкнена крива зі співвідношенням частот 2:3 |
| Граничний (пряма + мін. крок) | $A_x=1, A_y=1, f_x=1, f_y=1, \varphi_x=0^\circ, \varphi_y=0^\circ, \Delta t=0.05$ | Пряма діагональна лінія; рівно 20 кроків (21 точка) на період — гранично допустимий крок |
| Некоректні дані | $f_x=0$ або $-2$, $A_x=\text{"abc"}$, $\Delta t=0.06$ для $f=1$ Гц | Застосунок не завершується аварійно; під відповідним полем виводиться повідомлення про помилку |
