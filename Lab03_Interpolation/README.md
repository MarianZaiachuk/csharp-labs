# Лабораторна робота №3. Абстрактні класи та інтерполяція даних

## Мета роботи
Реалізувати поліморфну ієрархію класів для відновлення значень функції між опорними точками за допомогою лінійної та кубічної інтерполяції Ерміта, а також візуалізувати результати та графік похибки в WPF без залежності алгоритмів від інтерфейсу.

## Математична основа
1. **Лінійна інтерполяція** між сусідніми вузлами $(x_i, y_i)$ та $(x_{i+1}, y_{i+1})$:
   $$t = \frac{x - x_i}{x_{i+1} - x_i}, \qquad y = y_i + t(y_{i+1} - y_i)$$
2. **Кубічна інтерполяція Ерміта** на відрізку $\Delta x = x_{i+1} - x_i$:
   $$y(t) = h_{00}(t) y_i + h_{10}(t)\Delta x\, m_i + h_{01}(t) y_{i+1} + h_{11}(t)\Delta x\, m_{i+1}$$
   де $h_{00}=2t^3-3t^2+1$, $h_{10}=t^3-2t^2+t$, $h_{01}=-2t^3+3t^2$, $h_{11}=t^3-t^2$.
   Похідні $m_i$ оцінюються скінченними різницями: центральною $m_i = \frac{y_{i+1} - y_{i-1}}{x_{i+1} - x_{i-1}}$ для внутрішніх точок та односторонньою різницею для крайніх вузлів.

## Архітектура проєкту
- `InterpolationApp/Models/`:
  - `Interpolation` — абстрактний базовий клас з методом `Calculate(IReadOnlyList<PointD> points, double x)` та валідацією строгого зростання $x$;
  - `LinearInterpolation`, `HermiteInterpolation` — `sealed` реалізації інтерполяції;
  - `InterpolationExperiment` — табулювання опорного масиву $A_1$ (рівновіддаленого та нерівновіддаленого), сітки $A_2$, поліморфний розрахунок через масив `Interpolation[]` та обчислення абсолютної похибки $|y_{\text{інтерп}}(x) - f(x)|$.
- `InterpolationApp/ViewModels/MainViewModel.cs` — зберігає масив `Interpolation[]`, перевіряє умову $h_2 < h_1$, керує видимістю окремих `Polyline` через `CheckBox` та готує дані для двох графіків.
- `InterpolationApp/MainWindow.xaml` — розмітка з двома `Canvas` (графік функцій і графік похибок), чекбоксами видимості та полями введення `h1`, `h2`.
- `InterpolationApp.Tests/` — модульні тести (`xUnit`).

## Контрольні приклади
| Сценарій | Вхідні дані | Очікуваний результат |
|---|---|---|
| Точність у вузлах | $f(x)=\sin(x)$, рівновіддалені та нерівновіддалені вузли | Обидва методи у всіх вузлах $x_i$ дають $y_i$ з точністю $< 10^{-12}$ |
| Порівняння методів | $f(x)=\sin(x), h_1=0.8, h_2=0.05$ | Максимальна абсолютна похибка інтерполяції Ерміта менша за лінійну |
| Граничний / невалідний крок | $h_2 \ge h_1$ (наприклад, $h_1=0.5, h_2=0.6$) | Під полем `h2` з'являється повідомлення про помилку, програма не аваріює |
| Однакові або невпорядковані $x$ | Набір точок з $x_1 = x_2$ або $x_2 < x_1$ | `ValidateSupportPoints` кидає `ArgumentException` |
