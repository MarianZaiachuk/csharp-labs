# Лабораторна робота №4. Інтерфейси та чисельне інтегрування

## Мета роботи
Задати спільний контракт `IIntegrator` для різних методів чисельного інтегрування за шаблоном **Strategy**, одночасно порівняти результати й похибки у WPF `DataGrid` та побудувати графік збіжності при подвоєнні кількості інтервалів $n$.

## Математична основа
Для відрізка $[a, b]$, розбитого на $n$ рівних частин з кроком $h = \frac{b - a}{n}$ та вузлами $x_i = a + i h$:
- **Середні прямокутники:** $I \approx h \sum_{i=0}^{n-1} f\left(a + \left(i + \frac{1}{2}\right)h\right)$ — похибка $O(h^2)$.
- **Метод трапецій:** $I \approx h \left[\frac{f(x_0)}{2} + \sum_{i=1}^{n-1} f(x_i) + \frac{f(x_n)}{2}\right]$ — похибка $O(h^2)$.
- **Метод Сімпсона (парне $n \ge 2$):** $I \approx \frac{h}{3}\left[f(x_0) + 4\sum f(x_{2i-1}) + 2\sum f(x_{2i}) + f(x_n)\right]$ — похибка $O(h^4)$.

При $a > b$ крок $h < 0$, тому інтеграл природно змінює знак на протилежний, що узгоджується з аналітичним правилом $\int_a^b f(x)\,dx = -\int_b^a f(x)\,dx$. При подвоєнні $n$ методична похибка зменшується, доки не досягається межа похибок округлення чисел із рухомою комою (`double`, ~15–16 значущих цифр).

## Архітектура проєкту
- `IntegrationApp/Models/`:
  - `IIntegrator` — інтерфейс з `Integrate(Func<double, double> f, double a, double b, int intervals)`;
  - `RectangleIntegrator`, `TrapezoidIntegrator`, `SimpsonIntegrator` — незалежні стратегії (функція передається як делегат `Func<double, double>`);
  - `KnownFunction`, `IntegrationService` — аналітичні еталони ($F(b) - F(a)$), одночасне порівняння всіх стратегій та розрахунок збіжності для $n = 10, 20, 40, 80, 160$.
- `IntegrationApp/ViewModels/MainViewModel.cs` — працює виключно з `IIntegrator`, без окремого коду обчислення для кожного методу.
- `IntegrationApp/MainWindow.xaml` — вибір функції та активної стратегії через `ComboBox`, таблиця `DataGrid` і графік похибки на `Canvas`/`Polyline` (з опціональною шкалою $\log_{10}$).
- `IntegrationApp.Tests/` — модульні тести (`xUnit`).

## Контрольні приклади
| Сценарій | Вхідні дані | Очікуваний результат |
|---|---|---|
| Лінійна функція | $f(x)=x, [0, 1], n=10$ | Усі три методи повертають еталонне значення `0.5` |
| Тригонометрична функція | $f(x)=\sin(x), [0, \pi], n=100$ | Усі три методи наближають `2.0`, Сімпсон має найменшу похибку, а подвоєння $n$ зменшує похибку |
| Переставлені межі ($a > b$) | $f(x)=\sin(x), a=\pi, b=0$ | Усі методи повертають від'ємне значення `-2.0` |
| Непарне $n$ для Сімпсона | $n = 15$ | Прямокутники й трапеції обчислюються, у рядку Сімпсона виводиться контрольоване попередження без аварії |
